# 🕵️ Criminal Investigation Tracker with Suspect Prediction

An AI-powered web application that helps investigators manage criminal cases and predict suspect likelihood using Machine Learning.

## Features

- Add Criminal Cases
- Store Evidence Details
- Track Suspects
- SQLite Database Integration
- Machine Learning-Based Suspect Prediction
- Flask Web Interface
- Case Management Dashboard

## Technologies Used

- Python
- Flask
- SQLite
- NumPy
- Scikit-Learn
- HTML/CSS

## Machine Learning Model

The system predicts whether a person is a likely suspect based on:

- Prior Criminal Records
- Gang Association
- Violent History
